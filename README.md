# 王牌菜榜动效更新（Signature-Dish-Ranking-Motion-Update）

基于「王牌菜榜承接方案（方案二）」切出的动效迭代仓库，聚焦**榜单中心页王牌菜榜入口 icon 的强化动效**。

原方案：从王牌菜榜退出回到榜单中心页时，王牌菜榜 icon 播放一道白色扫光（1.6s）。
本仓库在同一承接链路（首页「点评榜单」→ 榜单中心页 → 王牌菜榜，上滑整页入场）上，提供 icon 强化动效的多方案对比。

## 方案切换组件

屏幕左缘悬浮气泡（外露一小部分，点开显示方案列表，选中后立即重播该方案动效）：

- **原方案**：现有动效 —— 单道白色扫光（1.6s），上滑整页（现状方案B）。
- **方案一 · 弹性放大 + 双重扫光**：icon 弹性放大回弹，白色与暖橙两道光束先后掠过。
- **方案二 · 橙色光晕脉冲扩散**：icon 呼吸放大 + 橙色光晕脉冲 + 两圈光环向外扩散。
- **方案三 · 星尘迸发**：icon 白光一闪 + 10 颗光点向四周迸发散开。

四个方案共用方案B 的王牌菜榜入场形态（上滑整页/返回箭头），仅 icon 强化动效不同。

## 动效触发时机

- **进入榜单中心页**：原方案保持现状（0.65s 后王牌菜榜直接上滑展开，icon 动效不播）；方案一/二/三先播 icon 强化动效，收尾后王牌菜榜再上滑展开。
- **从王牌菜榜返回榜单中心页**：所有方案均重播各自 icon 动效（核心对比场景）。
- **切换方案**：自动进入榜单中心页并立即重播完整链路，方便对比。

## 技术栈

Vite + React 18 + Tailwind CSS + shadcn/ui（脚手架来自 NoCode 平台标准模板）。

## 本地开发

```bash
npm install   # 或 yarn
npm run dev
```

## 分支说明

- `main` — 原方案二基线（未改动，作为【原方案】对照）。
- `motion-update` — 本动效迭代分支（方案切换组件 + 三个 icon 强化动效方案）。

## 目录结构

- `src/pages/Index.jsx` — 演示主容器（方案切换气泡、icon 强化动效、iframe 承载、状态栏覆盖层）
- `public/ace.html` + `public/assets/` — 王牌菜榜页面源文件与素材（本地预览可用）
- `src/assets/` — 首页图 / 榜单中心图 / 金刚区图标
