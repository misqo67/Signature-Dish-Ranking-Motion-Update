# 王牌菜榜动效更新（Signature-Dish-Ranking-Motion-Update）

基于「王牌菜榜承接方案（方案二）」切出的动效迭代仓库，聚焦**从王牌菜榜下滑退出回到榜单中心页时，王牌菜榜入口 icon 的强化动效**。

原方案：退出王牌菜榜回到榜单中心页时，icon 播放一道白色扫光（1.6s）。
本仓库在原方案（首页「点评榜单」→ 榜单中心页 → 王牌菜榜，上滑整页入场，全链路不变）的基础上提供强化对比。

## 方案切换组件

屏幕左缘悬浮气泡（外露一小部分，点开显示方案列表）：

- **原方案**：现有动效 —— 单道白色扫光（1.6s），上滑整页（现状方案B）。
- **方案一 · 退出时放大+扫光**：从王牌菜榜下滑退出后，icon 先弹性放大（0.6s，峰值 1.22x），随后播放原有扫光（1.6s）。
- **方案二 · 掀盖动画停末帧**：与原方案相同下滑收起；方案二的入口 icon 默认态为橙色餐盖（新动画第一帧），收起后播放掀盖动画（餐盖掀开露出王牌菜徽章，约 4s，由设计提供的 GIF 转逐帧 WebP），只播放一次并停留在最后一帧（王牌菜徽章）。其他方案默认态仍为王牌菜徽章 icon。
- **方案三 · 关闭缩回入口**：关闭时面板先原地缩小至 90%（0.18s），再位移至王牌菜榜入口中心、位移同时从 90% 缩到 0（0.36s，缓入缓出）并淡出；缩回即刻入口弹性放大回弹（0.4s，峰值 1.16x），回弹结束后接一道扫光（1.6s）。
- **方案四 · 聚光灯+引导提示**：与原方案相同下滑收起（icon 扫光不变）；收起后周边内容短暂压暗，入口保持明亮（白色聚光卡片），旁边出现「在这里，再看「王牌菜榜」」提示与「我知道了」按钮，短暂停留（约 2.4s）后自动消失、亮度恢复，也可点击提前关闭。

各方案共用方案B 的王牌菜榜入场形态（上滑整页/返回箭头），首页→榜单中心→王牌菜榜 全链路与现状一致，仅退出时刻的动效不同；所有方案均支持在王牌菜榜页顶部下拉（≥90px）关闭，方案三下拉时同样播放缩回入口动画。

## 动效触发时机

- **切换方案**：切换后自动返回首页，由用户从首页重新走完整链路。
- **进入榜单中心页**：从首页进入时王牌菜榜 icon 不播任何动效，0.65s 后王牌菜榜直接上滑展开（与现状一致）；关闭后再播该方案的强化动效。
- **从王牌菜榜下滑退出**：所有方案均重播各自 icon 动效（核心对比场景）。

## 技术栈

Vite + React 18 + Tailwind CSS + shadcn/ui（脚手架来自 NoCode 平台标准模板）。

## 本地开发

```bash
npm install   # 或 yarn
npm run dev
```

## 分支说明

- `main` — 原方案二基线（未改动，作为【原方案】对照）。
- `motion-update` — 本动效迭代分支（方案切换组件 + 方案一/方案二/方案三/方案四）。

## 目录结构

- `src/pages/Index.jsx` — 演示主容器（方案切换气泡、icon 强化动效、iframe 承载、状态栏覆盖层）
- `public/ace.html` + `public/assets/` — 王牌菜榜页面源文件与素材（本地预览可用）
- `src/assets/` — 首页图 / 榜单中心图 / 金刚区图标
