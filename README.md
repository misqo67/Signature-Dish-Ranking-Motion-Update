# 王牌菜榜动效更新（Signature-Dish-Ranking-Motion-Update）

基于「王牌菜榜承接方案（方案二）」切出的动效迭代仓库，聚焦**从王牌菜榜下滑退出回到榜单中心页时，王牌菜榜入口 icon 的强化动效**。

原方案：退出王牌菜榜回到榜单中心页时，icon 播放一道白色扫光（1.6s）。
本仓库在原方案（首页「点评榜单」→ 榜单中心页 → 王牌菜榜，上滑整页入场，全链路不变）的基础上提供强化对比。

## 方案切换组件

屏幕左缘悬浮气泡（外露一小部分，点开显示方案列表）：

- **原方案**：现有动效 —— 单道白色扫光（1.6s），上滑整页（现状方案B）。
- **方案一 · 退出时放大+扫光**：从王牌菜榜下滑退出后，icon 先弹性放大（0.6s，峰值 1.22x），随后播放原有扫光（1.6s）。

两个方案共用方案B 的王牌菜榜入场形态（上滑整页/返回箭头），首页→榜单中心→王牌菜榜 全链路与现状一致，仅退出时刻的 icon 动效不同。

## 动效触发时机

- **进入榜单中心页**：两个方案均保持现状（0.65s 后王牌菜榜直接上滑展开，不播 icon 动效）。
- **从王牌菜榜下滑退出**：所有方案均重播各自 icon 动效（核心对比场景）。

## 技术栈

Vite + React 18 + Tailwind CSS + shadcn/ui（脚手架来自 NoCode 平台标准模板）。

## 本地开发

```bash
npm install   # 或 yarn
npm run dev
```

## 分支说明

- `main` — 原方案二基线（未改动，作为【原方案】对照）。
- `motion-update` — 本动效迭代分支（方案切换组件 + 方案一）。

## 目录结构

- `src/pages/Index.jsx` — 演示主容器（方案切换气泡、icon 强化动效、iframe 承载、状态栏覆盖层）
- `public/ace.html` + `public/assets/` — 王牌菜榜页面源文件与素材（本地预览可用）
- `src/assets/` — 首页图 / 榜单中心图 / 金刚区图标
